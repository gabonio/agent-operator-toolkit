# Coding Standards Guides

These are lightweight language-specific checklists for AI-assisted changes.

Use only the guide that matches the code you are touching:

- [CPP.md](./CPP.md): C and C++ projects
- [FRONTEND.md](./FRONTEND.md): browser UIs and frontend applications
- [JAVA.md](./JAVA.md): Java services and backend applications
- [PYTHON.md](./PYTHON.md): Python scripts, CLIs, and services
- [SHELL.md](./SHELL.md): shell scripts and local automation

These guides are not a substitute for project-specific conventions. When the project already has its own standards, follow the project first and use these as a fallback.
