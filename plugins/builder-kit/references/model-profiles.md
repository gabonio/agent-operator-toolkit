# Model Profiles

Choose capabilities, not permanent model names.

## Planning profile

Use a higher-reasoning model for ambiguous discovery, architecture, specifications, tradeoffs, adversarial review, and producing a literal executor plan.

## Execution profile

After approval, use a faster, lower-cost model that can follow the plan, edit safely, use tools, run tests/builds, and stop on material drift. Increase reasoning only when representative results show a quality gain.

Current owner-provided examples as of 2026-08-04: Sol medium for planning; Luna high or extra high for execution. Treat these as dated examples. Refresh recommendations through representative Builder Kit evaluations as models change.
