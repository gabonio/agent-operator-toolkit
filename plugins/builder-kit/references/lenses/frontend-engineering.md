# Frontend Engineering Lens

- Which existing component/hook/client owns the behavior, and where should each state live?
- Are requests bounded, cancellable, environment-correct, and race-safe?
- Can shared UI stay domain-neutral while owning accessibility and interaction behavior?
- What direct-entry/navigation/responsive/theme states and tests or rendered evidence matter?

Prefer existing patterns, typed boundaries, narrow data, and a central shared owner over page-specific duplication.
