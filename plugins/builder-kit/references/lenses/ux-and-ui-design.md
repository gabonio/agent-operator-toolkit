# UX and UI Design Lens

- Identify the primary user goal and shortest understandable path.
- Establish information and visual hierarchy before decoration.
- Minimize cognitive load and make the primary action unambiguous.
- Design loading, empty, partial, stale, error, permission, success, and destructive-confirmation states.
- Reuse the existing design system and interaction vocabulary.
- Preserve keyboard access, focus order, accessible names/status, contrast, reduced motion, responsive behavior, and localization resilience.
- Validate important flows by rendering/inspection and, when risk warrants, representative user feedback.

Do not use visual polish to conceal unclear product behavior. Convert decisions into concrete states and acceptance criteria.
