# UX and UI Design Lens

- Identify the primary goal, shortest understandable path, and clear visual hierarchy.
- Make the primary action unambiguous and design only relevant loading/empty/error/permission/success/destructive states.
- Reuse the existing design system and interaction vocabulary.
- Preserve keyboard/focus, accessible names/status, contrast, reduced motion, responsive behavior, and localization.
- Validate important flows by rendering and, when warranted, representative user feedback.

Do not use visual polish to conceal unclear product behavior. Convert decisions into concrete states and acceptance criteria.
