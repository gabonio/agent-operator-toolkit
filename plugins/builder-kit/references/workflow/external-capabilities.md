# External capability routing

Builder Kit owns the development process. Repository- or platform-specific skills own specialized knowledge.

- Prefer an installed, explicitly relevant skill or tool over recreating its handbook inside Builder Kit.
- Read the capability's instructions before invoking it and preserve its approval and safety boundaries.
- If a required capability is unavailable, name the missing capability and continue only with a safe, evidence-backed fallback.
- Do not silently install plugins, invent organization-specific commands, or assume access to proprietary systems.
- Keep platform-specific rules in the repository or plugin that owns them.
